# SPEC.md — Smart Roster Management System (Datastraw Assessment)

## 1. System Overview
An enterprise D2C Operations Roster Management System that plans, generates, validates, and manages monthly schedules for 32+ employees across 20 D2C brands, 4 operational processes, and 3 pods.
Core priority: Deterministic scheduling accuracy, strict distinction between Brand Operating Calendars and Employee Schedules, real-time conflict detection, and graceful handling of mid-month availability changes without full roster rebuilds.

## 2. Tech Stack & Directory Structure
- **Backend (`/backend`)**: Python 3.11+, FastAPI, SQLAlchemy (SQLite `roster.db`), Pydantic v2.
- **Frontend (`/frontend`)**: React 18 (Vite), Tailwind CSS, Lucide React, Axios/Fetch.
- **Port Config**: Backend on `http://localhost:8000`, Frontend on `http://localhost:5173` (with CORS enabled for `*`).
